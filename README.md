# CardKeep

Гаманець для скидочних карток, у якому дані належать вам.

**▶ Відкрити застосунок: [sobchenyuk.github.io/cardkeep](https://sobchenyuk.github.io/cardkeep/)**

На телефоні: відкрийте посилання → «Додати на головний екран» (iOS: Поділитися → На початковий екран).

- Скануйте штрих-код або QR, фотографуйте картку з обох боків, додавайте опис і категорію.
- Працює офлайн і встановлюється на телефон прямо з браузера (Android та iOS).
- Повна копія всіх карток — одним ZIP-архівом, який відкривається навіть без застосунку.
- Без реклами, без акаунтів, без трекерів.
