# Memory — де ми зупинились

Журнал прогресу. Оновлювати в кінці кожної робочої сесії: що зроблено, що далі, які рішення ухвалено.

## Ключові рішення

- 2026-11-22 — Фото стискаються **на телефоні** (≈1200 px, WebP ~0.75), не на сервері.
- 2026-11-22 — Експорт/імпорт — **ZIP-архів** (`cards.json` + `photos/`), а не один файл.
- 2026-11-22 — Код штрих-коду/QR зберігається лише як значення, картинка генерується.

- 2026-11-22 — Категорії динамічні, повний CRUD користувачем; одна категорія на картку.
- 2026-11-22 — Дизайн: стиль 4 «Плитка» — лавандовий фон, фіолетовий акцент (#6a4cff / темна #9d8bff), сітка карток у 2 колонки, плаваюча нижня панель, великі заокруглення.

## Примітки

- Роутинг у hash-режимі (`/#/settings`) через GitHub Pages. Відкрита картка — query `?card=<id>`, щоб «назад» закривав шторку.
- Код картки **без обмежень** довжини й символів (рішення автора). Якщо код не підходить під обраний формат (напр. 2 цифри як EAN-13), він малюється як Code 128.
- Після збереження форма закривається і відразу відкривається картка; на головну користувач повертається сам (свайп униз / «назад»). Toast: «Картку «…» додано» / «Зміни збережено».
- Свайп униз — touch-події з passive:false (pointer-події на телефоні перехоплює прокрутка браузера).
- Фото сторін: натискання на «Лицьова/Зворотна» відкриває власну камеру (`?photo=front|back`) з рамкою картки й кропом по рамці; «Галерея» — всередині камери.
- Поля «Формат коду» в формі **немає** (рішення автора): формат береться зі сканера/фото, а для введеного вручну — `auto` (13 цифр → EAN-13, 12 → UPC-A, 8 → EAN-8, інше → Code 128).
- Сканер відкривається як `?scan=1` у формі, щоб кнопка «назад» на телефоні закривала його.
- Попередній перегляд імпорту тримати в `shallowRef`: IndexedDB не клонує Vue-проксі (DataCloneError).
- Видалення картки/категорії — подвійне натискання (без модальних діалогів).
